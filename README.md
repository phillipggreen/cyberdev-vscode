## Installation via VS Code

1. Open the **Extensions** view in VS Code (`Ctrl+Shift+X` / `Cmd+Shift+X` on macOS)
2. Search for `CyberDev`
3. Click **Install**
4. Open the Color Theme picker with `Ctrl+K Ctrl+T` (`Cmd+K Cmd+T` on macOS), or run **Preferences: Color Theme** from the Command Palette
5. Select **CyberDev**

## Manual Installation

Read the [VSC Extension Quickstart Guide](https://github.com/phillipggreen/cyberdev-vscode/blob/master/vsc-extension-quickstart.md)

## Icon Theme

The file icon theme recommended for use with CyberDev is [Material Icon Theme](https://marketplace.visualstudio.com/items?itemName=PKief.material-icon-theme) with these settings:

```json
"material-icon-theme.folders.color": "#00FFFF",
"material-icon-theme.folders.theme": "specific",
"material-icon-theme.hidesExplorerArrows": true
```
